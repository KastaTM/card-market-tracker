## Access, license, and cost

- **Documented:** Cardmarket is *not accepting applications* for new API access. Its API authentication page additionally describes manual approval restricted to professional sellers. API requests require OAuth credentials; dedicated-app credentials must not be shared. The dedicated-app policy explicitly disallows consecutive-day, repeated requests solely to public marketplace resources, especially exhaustion of limits. [Help](https://help.cardmarket.com/en/cardmarket-api); [authentication](https://apiv2.cardmarket.com/ws/documentation/API%3AAuth_Overview).
- **Documented:** The current GTC §9 states that API use is for managing the user's own content, and showing trading cards and their prices needs prior written agreement; other API data uses are prohibited. CMT's planned market-history and comparison use does not fit that grant as written. No retention or redistribution permission for a CMT historical database was found. A prior written agreement would have to address these uses explicitly before reconsideration. [GTC §9](https://www.cardmarket.com/en/Pokemon/Policies/GeneralTermsAndConditions/ES).
- **Documented:** API limits are described as 5,000/day for private dedicated apps, 100,000/day for commercial, and 1,000,000/day for powersellers, reset at midnight CET/CEST. Marketplace requests have a separate 30,000/day cap and one concurrent request per IP; 429/503 responses are documented. These quotas are **not** permission for CMT's proposed collection. Published API price or access fee for this use was not established; account registration is described as free, which does not imply API access is available. [Response codes](https://apiv2.cardmarket.com/ws/documentation/API_2.0%3AResponse_Codes); [API news](https://apiv2.cardmarket.com/ws/documentation); [GTC](https://www.cardmarket.com/en/Pokemon/Policies/GeneralTermsAndConditions/ES).
- **Documented:** API 2.0 moved to `apiv2.cardmarket.com`, with a May 1, 2026 migration deadline. The product-list and price-guide bulk files were deprecated in 2024; the price-guide file has a selected-user restriction and daily refresh. Do not design a new integration against the older host or the deprecated bulk file. [API news](https://apiv2.cardmarket.com/ws/documentation); [price guide](https://apiv2.cardmarket.com/ws/documentation/API_2.0%3APriceGuide).

## Observation, inference, and decision

**Observed:** public documentation was readable on the consultation date; no API response, payload, account entitlement, live price, listing, or stock state was observed. No data samples or secrets were retained.

**Inferred from the written rules:** even if an existing account had technical access, CMT's planned repeated marketplace collection, cross-source price analysis, and historical storage would need an explicit compatible agreement. The published new-application closure makes Cardmarket unavailable as a new primary P2 source now. This inference is about the proposed use, not a legal determination on all possible uses.

**Decision for the source matrix:** `REJECTED` as an available recurring CMT market feed. Reopen only after Cardmarket confirms API access and grants the intended collection, retention, derived analytics, and display rights in writing. Do not scrape the storefront or use someone else's token as a workaround. Its price data may explain the provenance of a third-party aggregate, but that aggregate is not an independent Cardmarket feed.
