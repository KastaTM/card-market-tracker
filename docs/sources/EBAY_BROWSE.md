## Access, license, and cost

- **Documented:** Browse requires an OAuth *application* access token from client credentials. A developer account and application keyset are required; sandbox access is available to developer accounts, whereas production Buy API access is intended for approved partners and requires business review and contracts. Approval is not guaranteed. No account, keyset, or approval was present for this task. [Buy API overview](https://developer.ebay.com/develop/api/buy); [requirements](https://developer.ebay.com/api-docs/buy/buy-requirements.html); [application process](https://developer.ebay.com/develop/get-started/get-started-on-a-buying-application).
- **Documented:** the default Browse quota is 5,000 calls/day for methods other than `getItems`, with a separate 5,000/day for `getItems`; Buy APIs require an additional license. No quoted production fee or guarantee of free production use was found. Higher limits require eBay review. [Call limits](https://developer.ebay.com/develop/get-started/api-call-limits).
- **Documented:** the current license permits limited intermediate copies only for an allowed activity and requires deletion when no longer needed. Public-display content must be removed when no longer publicly available; displayed listing information must be kept within six hours of eBay's current information, and other displayed content within 24 hours. It restricts commingling eBay content with non-eBay content and prior written permission is required for specified derived statistics. It also restricts storage, distribution, and price-model uses outside the license grant. A durable multi-source CMT price history or comparison cannot be assumed permitted; obtain explicit license review/permission first. [API License Agreement §§3, 8–9](https://developer.ebay.com/join/api-license-agreement).
- **Documented:** Marketplace Insights, the separate sales-history API, is restricted and not open to new users. Browse's available listings must not be labeled completed sales. [Marketplace support](https://developer.ebay.com/api-docs/buy/static/ref-marketplace-supported.html); [production access guide](https://developer.ebay.com/develop/get-started/get-started-on-a-buying-application).

## Observation, inference, and decision

**Observed:** official public documentation was readable on the consultation date. No authenticated endpoint was probed, no sample listing was retained, and the Spanish Pokémon coverage, fields, currency and shipping remain unverified. A successful sandbox response would use test data and would not establish production approval or market coverage.

**Inferred from the license and access requirements:** Browse could help discover currently active offers if eBay approves CMT's use and the resulting license allows the intended local storage and comparison. Its standard license language is a material obstacle to CMT's historical-first, multi-source market analytics. The quoted six-hour freshness rule applies to **displayed** listings; it is not a grant of six-hour retention for a historical database.

**Decision for the source matrix:** `CONDITIONAL` for narrow active-listing discovery; do not plan P2 reference pricing, sold-price history, or durable cross-source analytics on Browse without explicit permission. If the use case is rejected by eBay, classify the production path `REJECTED`. Prefer a separate source with clear storage and analytics rights for P2. No scraping or account creation is authorized by this fiche.
